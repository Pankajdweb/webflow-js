Accordion Component

A lightweight, accessible accordion for FAQ sections. Pure vanilla JS — no dependencies. Smooth height transitions, ARIA roles, keyboard navigation, and semantic FAQ schema markup out of the box.

Zero dependencies ARIA accessible Smooth transitions Keyboard nav FAQ schema markup Multiple groups
1

Introduction

The Accordion component is an accessible, attribute-driven UI pattern for FAQ sections, product help pages, and anywhere you need to show-or-hide content. It initialises entirely from HTML attributes — no extra classes, no config objects — making it trivial to drop into Webflow, plain HTML, or any CMS.

Each [accordian-list] wrapper creates an isolated group. When a user opens one item, the others in the same group close automatically. Multiple lists on a page are fully independent. The JS handles smooth height animation, aria-expanded state, and the inert attribute to block focus on collapsed panels.

Note: The attribute spelling is intentionally accordian (not accordion) to match the original Webflow implementation. Keep spelling consistent across your HTML and JS.

// accordion.min.js — self-initialising, zero dependencies
(function () {
  function initAccordion() {
    var groups = document.querySelectorAll("[accordian-list]");
    groups.forEach(function(group, gi) {
      var items = group.querySelectorAll("[accordian]");
      items.forEach(function(item, ii) {
        var head = item.querySelector("[accordian-head]");
        var body = item.querySelector("[accordian-body]");
        if (!head || !body) return;
        head.id = "faq-head-" + gi + "-" + ii;
        body.id = "faq-panel-" + gi + "-" + ii;
        head.setAttribute("aria-controls", body.id);
        head.setAttribute("aria-expanded", "false");
        body.setAttribute("role", "region");
        body.setAttribute("aria-labelledby", head.id);
        body.style.overflow   = "hidden";
        body.style.transition = "height 0.3s ease";
        body.style.height     = "0px";
        body.setAttribute("inert", "");
        head.addEventListener("click", function() { toggle(items, head, body); });
        head.addEventListener("keydown", function(e) {
          if (e.key === "Enter" || e.key === " ") { e.preventDefault(); toggle(items, head, body); }
        });
      });
    });
  }
  function toggle(items, head, body) {
    var isOpen = head.getAttribute("aria-expanded") === "true";
    items.forEach(function(i) {
      var h = i.querySelector("[accordian-head]");
      var b = i.querySelector("[accordian-body]");
      h.classList.remove("open"); h.setAttribute("aria-expanded", "false");
      b.style.height = "0px"; b.setAttribute("inert", "");
    });
    if (!isOpen) {
      head.classList.add("open"); head.setAttribute("aria-expanded", "true");
      body.style.height = body.scrollHeight + "px"; body.removeAttribute("inert");
    }
  }
  document.readyState === "loading"
    ? document.addEventListener("DOMContentLoaded", initAccordion)
    : initAccordion();
})();

Accordion attribute reference

AttributeElementRequiredWhat it does
accordian-list Wrapper <div> Required Marks the accordion group. JS scopes the "close others" logic per group — multiple lists on a page are fully independent.
accordian Item <div> Required Marks one accordion item. JS queries all [accordian] elements inside the parent list. Add one per Q&A pair.
accordian-head <button> Required The clickable trigger. JS attaches click/keydown listeners, manages aria-expanded, and toggles .open to animate the icon via CSS.
accordian-body Collapsible <div> Required The panel that expands. JS animates height from 0 to scrollHeight on open. Toggles inert to block keyboard focus when collapsed.

Schema.org FAQ attribute reference

Minimum CSS

/* Body starts collapsed — JS animates height */
.accordian-body {
  overflow: hidden;
  transition: height 0.3s ease;
  height: 0;
}
/* Rotate the + icon to × when open */
[accordian-head].open .accordian-icon-wrap {
  transform: rotate(45deg);
  transition: transform 0.3s ease;
}
That's all the CSS needed. The JS handles all height toggling via inline styles — your stylesheet only needs the transition and initial height: 0.
