Copy & Paste into Webflow

Click the Copy For Webflow button above — the component is instantly copied to your clipboard. Open your Webflow project in the Designer, click anywhere on the canvas, and press Cmd / Ctrl + V to paste. The full navbar — structure, styles, and all — drops straight in, ready to use.

Fully Responsive

The navbar is built to look great on every device. On desktop it displays a horizontal link row. On tablets and mobiles it collapses into a full-screen overlay menu triggered by an animated hamburger button — no extra setup required.

Zero Dependencies

No JavaScript libraries, no npm packages, no third-party scripts. The hamburger animation and scroll-lock behaviour run entirely on CSS, using Webflow's native w--open class — keeping your project fast and clean.

Easy to Customise

Every part of the navbar is styled with named Webflow classes. Update colours, fonts, spacing, or link labels directly in the Style Panel — no code editing needed. Swap the logo text for an image in seconds.

Fixed & Always Visible

The navbar is fixed to the top of the viewport so it stays visible as users scroll through your page. The background starts transparent — ideal for layering over hero sections — and can easily be set to a solid colour via the Style Panel.

See the navbar in action — resize the window to trigger the mobile hamburger menu. The overlay takes full viewport height and locks body scroll until closed.
