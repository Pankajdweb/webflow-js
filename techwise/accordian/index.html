Accordian Element

Flexible and accessible accordion component for Webflow projects with schema support, smooth animations, and developer-friendly integration.

The accordion is a UI pattern that shows one expanded content panel at a time. Ideal for FAQs, settings menus, and content-heavy pages.

Drop in the CDN script tag before the closing </body> tag, then wrap your content using the required tw-accordion data attributes on the wrapper, each item, trigger, and answer element.

Yes. The component ships with full Schema.org FAQPage markup baked in. Google can read and display your accordion Q&A directly in search results as rich snippets.

Overview

The TechWise Accordion is a lightweight, dependency-free vanilla JS component. It handles open/close toggling, smooth height animations, keyboard navigation, ARIA attributes, and Schema.org FAQPage markup — all from a single script tag. One item is open at a time; clicking an open item closes it.

Option 1 — CDN

The quickest way to get started. Paste the script tag anywhere in your HTML — typically just before the closing </body> tag. 

<!-- TechWise Accordion — CDN -->
<script src="https://jswebflow.netlify.app/techwise/accordian/script.js" defer></script>

OR

Option 2 — Self-hosted script

Instead of loading via CDN, you can paste the JavaScript code directly into your page using a script tag — no external dependency needed. 

<!-- TechWise Accordion — self-hosted -->
<script> 
(function () {
  function initAccordion() {
    const groups = document.querySelectorAll("[tw-accordion='wrapper']");

    groups.forEach((group, groupIndex) => {
      const items = group.querySelectorAll("[tw-accordion='item']");

      items.forEach((item, itemIndex) => {
        const head = item.querySelector("[tw-accordion='trigger']");
        const body = item.querySelector("[tw-accordion='answer']");
        if (!head || !body) return;

        /* -----------------------------
           Generate unique IDs
        ----------------------------- */
        const headId = `faq-head-${groupIndex}-${itemIndex}`;
        const bodyId = `faq-panel-${groupIndex}-${itemIndex}`;
        head.id = headId;
        body.id = bodyId;

        /* -----------------------------
           ARIA setup
        ----------------------------- */
        head.setAttribute("aria-controls", bodyId);
        head.setAttribute("aria-expanded", "false");
        body.setAttribute("role", "region");
        body.setAttribute("aria-labelledby", headId);

        /* -----------------------------
           Initial styles
        ----------------------------- */
        body.style.overflow = "hidden";
        body.style.transition = "height 0.3s ease";
        body.style.height = "0px";

        // Default: disable focus
        body.setAttribute("inert", "");

        // If pre-opened
        if (head.classList.contains("open")) {
          body.style.height = body.scrollHeight + "px";
          head.setAttribute("aria-expanded", "true");
          body.removeAttribute("inert"); // allow focus
        }

        /* -----------------------------
           Toggle logic
        ----------------------------- */
        const toggleAccordion = () => {
          const isOpen = head.getAttribute("aria-expanded") === "true";

          // Close all in this group
          items.forEach((i) => {
            const h = i.querySelector("[tw-accordion='trigger']");
            const b = i.querySelector("[tw-accordion='answer']");

            h.classList.remove("open");
            h.setAttribute("aria-expanded", "false");

            b.style.height = "0px";
            b.setAttribute("inert", ""); // block focus
          });

          // Open current if it was closed
          if (!isOpen) {
            head.classList.add("open");
            head.setAttribute("aria-expanded", "true");

            body.style.height = body.scrollHeight + "px";
            body.removeAttribute("inert"); // allow focus
          }
        };

        /* -----------------------------
           Events
        ----------------------------- */
        head.addEventListener("click", toggleAccordion);

        head.addEventListener("keydown", (e) => {
          if (e.key === "Enter" || e.key === " ") {
            e.preventDefault();
            toggleAccordion();
          }
        });
      });
    });
  }

  /* Safe init */
  if (document.readyState === "loading") {
    document.addEventListener("DOMContentLoaded", initAccordion);
  } else {
    initAccordion();
  }
})();
</script>

Option 3 — Full HTML markup

Copy the markup below and paste it into your page. Each tw-accordion="item" block is one accordion entry. Duplicate the item block as many times as you need and update the heading text and body content. 

<div
  itemscope=""
  tw-accordion="wrapper"
  itemtype="https://schema.org/FAQPage"
>

  <!-- Accordion item — duplicate this block for each Q&A -->
  <div
    tw-accordion="item"
    itemscope=""
    itemprop="mainEntity"
    itemtype="https://schema.org/Question"
  >
    <button tw-accordion="trigger">
      <h3 itemprop="name">Your question here</h3>
      <svg
        viewBox="0 0 14 14"
        fill="none"
        stroke="currentColor"
        stroke-width="2"
      >
        <path d="M7 2v10M2 7h10"></path>
      </svg>
    </button>

    <div
      tw-accordion="answer"
      itemscope=""
      itemprop="acceptedAnswer"
      itemtype="https://schema.org/Answer"
    >
      <div itemprop="text">
        <p>Your answer goes here.</p>
      </div>
    </div>
  </div>

</div>

Overview

The steps below walk you through adding the TechWise Accordion to any Webflow project — no custom code experience required. You will add one script tag in Project Settings and then paste the pre-built Webflow element directly into your canvas using the Copy Element button.

Step 1 — Add the script

In Webflow, go to Project Settings → Custom Code → Footer Code and paste the snippet below. This loads the accordion logic on every published page. 

<!-- TechWise Accordion — paste in Webflow Footer Code -->
<script src="https://jswebflow.netlify.app/techwise/accordian/script.js" defer></script>

Step 2 — Copy the Webflow element

Click Copy Accordion below. Then open your Webflow project, click anywhere on the canvas, and press Ctrl + V (Windows) or Cmd + V (Mac) to paste. The full accordion structure — including classes, attributes, and schema markup — will appear instantly.
