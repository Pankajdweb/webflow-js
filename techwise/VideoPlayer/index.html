Overview

The TechWise Universal Video Player is a lightweight, dependency-free vanilla JS component. Drop in the CSS and JS from the CDN, add the required HTML structure with a tw-data-video-url attribute, and you get a fully functional, accessible video player — for YouTube, Vimeo, MP4, or WebM.

Step 1 — Add the CDN

Paste the CSS link in your <head> and the JS script just before the closing </body> tag. 

<!-- TechWise Video Player CSS -->
<link rel="stylesheet" href="https://jswebflow.netlify.app/techwise/videoplayer/style.css" />

<!-- TechWise Video Player JS -->
<script src="https://jswebflow.netlify.app/techwise/videoplayer/script.js" defer></script>

1. tw-data-video-url — Required

This is the only required attribute. Set it on the .tw-vp-wrapper element to the URL of your video. The player automatically detects the source type — YouTube, Vimeo, MP4, or WebM — and handles everything from there. 

<!-- YouTube -->
<div class="tw-vp-wrapper" tw-data-video-url="https://youtu.be/gSoyOSvjuWw">...</div>

<!-- Vimeo -->
<div class="tw-vp-wrapper" tw-data-video-url="https://vimeo.com/1115490186">...</div>

<!-- MP4 / WebM -->
<div class="tw-vp-wrapper" tw-data-video-url="https://example.com/video.mp4">...</div>

2. tw-data-autoplay — Optional

Add the tw-data-autoplay attribute (no value needed) to make the video autoplay muted on page load, with looping enabled and controls hidden. Ideal for hero section background videos. 

<div
  class="tw-vp-wrapper"
  tw-data-video-url="https://example.com/video.mp4"
  tw-data-autoplay
>
  <div class="tw-vp-container">
    <div class="tw-vp-thumbnail-holder">
      <img src="" alt="" class="tw-vp-thumbnail" />
    </div>
  </div>
</div>

3. Thumbnail — Auto or Custom

The .tw-vp-thumbnail image controls what's shown before the video plays. You have two options:

Auto-generated — Leave src="" empty. The player will automatically generate a thumbnail by seeking into the video (for MP4/WebM) or fetching it from the platform API (for YouTube and Vimeo).

Custom thumbnail — Set src to your own image URL to use a custom poster image instead. 

<!-- Auto-generated thumbnail (leave src empty) -->
<img src="" alt="" class="tw-vp-thumbnail" />

<!-- Custom thumbnail (add your image URL to src) -->
<img src="https://example.com/my-poster.jpg" alt="Video poster" class="tw-vp-thumbnail" />

Full HTML Markup

Copy the complete structure below and paste it into your page. Update tw-data-video-url with your video URL and optionally add tw-data-autoplay or a custom thumbnail src. 

<div
  class="tw-vp-wrapper"
  tw-data-video-url="YOUR_VIDEO_URL_HERE"
  aria-label="Video player"
>
  <div class="tw-vp-container">
    <div class="tw-vp-thumbnail-holder">
      <img src="" alt="" class="tw-vp-thumbnail" />
    </div>
  </div>
</div>

Overview

The steps below walk you through adding the TechWise Video Player to any Webflow project — no custom code experience required. Add the CDN links in Project Settings, then paste the pre-built element directly into your canvas using the Copy Element button.

Step 1 — Add the CDN

In Webflow, go to Project Settings → Custom Code. Paste the CSS link into the Head Code section and the JS script into the Footer Code section. This loads the video player on every published page. 

<!-- Paste in Head Code -->
<link rel="stylesheet" href="https://jswebflow.netlify.app/techwise/videoplayer/style.css" />

<!-- Paste in Footer Code -->
<script src="https://jswebflow.netlify.app/techwise/videoplayer/script.js" defer></script>

Step 2 — Copy the Webflow Element

Click Copy Element below. Then open your Webflow project, click anywhere on the canvas, and press Ctrl + V (Windows) or Cmd + V (Mac) to paste. The full video player structure — including classes and attributes — will appear instantly.

Step 3 — Set Your Video URL

After pasting the element, select the outer .tw-vp-wrapper div in the Webflow Navigator. In the Element Settings panel, find the custom attribute tw-data-video-url and update its value to your video URL (YouTube, Vimeo, MP4, or WebM).

To enable autoplay, add a new custom attribute named tw-data-autoplay with no value. To use a custom thumbnail, select the .tw-vp-thumbnail image element and set its src to your poster image URL.

Step 4 — HTML Reference

If you prefer to build the structure manually using Webflow's Embed element, use the markup below as your reference. Only tw-data-video-url is required; tw-data-autoplay is optional. 

<div
  class="tw-vp-wrapper"
  tw-data-video-url="YOUR_VIDEO_URL_HERE"
  aria-label="Video player"
>
  <div class="tw-vp-container">
    <div class="tw-vp-thumbnail-holder">
      <img src="" alt="" class="tw-vp-thumbnail" />
    </div>
  </div>
</div>
