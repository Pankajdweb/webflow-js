Overview

The TechWise Popup component is a lightweight, dependency-free vanilla JS modal system. Two variants are available: a center modal that overlays the page content, and a side drawer that slides in from the right. Both share the same trigger and close attributes — only the modal body class differs.

How it works

Three custom attributes drive everything. A trigger button carries tw-modal-trigger with a numeric value. The modal wrapper carries tw-modal-content with the matching value. Any close element carries tw-modal-close. The JS wires them up automatically — no IDs or event listeners needed in your own code.

Required attributes

tw-modal-trigger="N" — Add to any button or element that should open a popup. Set the value to a number (e.g. 1, 2) that matches the corresponding tw-modal-content. 

<button tw-modal-trigger="1">Open Popup</button>

tw-modal-content="N" — Add to the outermost .tw_modal wrapper div. Must match the trigger value. The popup is hidden by default and shown when its trigger is clicked. 

<div tw-modal-content="1" class="tw_modal">...</div>

tw-modal-close — Add to any element inside the popup to make it close the modal. Used on both the × button and the backdrop overlay. No value needed. 

<button tw-modal-close>Close</button>
<!-- or on the backdrop div -->
<div tw-modal-close class="tw_modal-close"></div>

Required CSS classes

The popup relies on a small set of structural classes. Do not rename them — the JS and CSS both depend on them. Paste all of the CSS below into your project's stylesheet or a custom code block.

.tw_modal {
  position: fixed;
  inset: 0%;
  z-index: 100;
  display: none;
  width: 100vw;
  height: 100dvh;
}

/* Dark backdrop flex container */
.tw_modal-base {
  display: flex;
  flex-flow: column;
  justify-content: center;
  align-items: center;
  height: 100%;
  background-color: #000000b3;
}

/* Center modal panel (Variant 1) */
.tw_modal-body {
  position: relative;
  z-index: 2;
  overflow: hidden;
  width: 100%;
  max-width: 75%;
  border-radius: 1rem;
  background-color: #fff;
}

@media (max-width: 991px) { .tw_modal-body { max-width: 90%; } }

The popup opens centered over the page with a dark backdrop. Uses .tw_modal-body (max-width 75%) and .tw_modal-scroll (max-height 90vh). Best for confirmation dialogs, forms, and rich content.

JS — Popup Script

Paste this script just before the closing </body> tag. It handles open, close, backdrop click, ESC key, and body scroll lock automatically for any number of popups on the page. 

<script>
  document.addEventListener("DOMContentLoaded", function () {
    const twModalTrigger = document.querySelectorAll("[tw-modal-trigger]");
    const twModals = document.querySelectorAll("[tw-modal-content]");

    // Hide all popups initially
    twModals.forEach((popup) => {
      popup.style.opacity = "0";
      popup.style.display = "none";
    });

    // Reusable close function
    function closePopup(popup) {
      if (!popup || popup.style.opacity === "0") return;

      popup.style.transition = "opacity 0.3s ease";
      popup.style.opacity = "0";

      popup.addEventListener("transitionend", function handler() {
        popup.style.display = "none";
        document.body.style.overflow = "auto";
        popup.removeEventListener("transitionend", handler);
      });
    }

    // Show popup on button click
    twModalTrigger.forEach((btn) => {
      btn.addEventListener("click", function () {
        const popupAttr = this.getAttribute("tw-modal-trigger");
        if (!popupAttr) return;

        const popup = document.querySelector(`[tw-modal-content="${popupAttr}"]`);
        if (popup) {
          popup.style.display = "block";
          popup.getBoundingClientRect(); // Trigger reflow
          popup.style.transition = "opacity 0.5s ease";
          popup.style.opacity = "1";
          document.body.style.overflow = "hidden";
        }
      });
    });

    // Close popup via close button or backdrop
    document.querySelectorAll("[tw-modal-close]").forEach((closeBtn) => {
      closeBtn.addEventListener("click", function () {
        closePopup(this.closest("[tw-modal-content]"));
      });
    });

    // Close popup via ESC key
    document.addEventListener("keydown", function (e) {
      if (e.key !== "Escape") return;

      const openPopup = [...twModals].find((p) => p.style.opacity === "1");
      if (openPopup) closePopup(openPopup);
    });
  });
</script>

Overview

The steps below walk you through adding the TechWise Popup to any Webflow project. Two variants are available: a center modal and a side drawer. Use the Copy Element buttons below to paste the right structure directly into your Webflow canvas.

Step 1 — Add the popup script

In Webflow, go to Project Settings → Custom Code. Paste the script below into the Footer Code section. This enables the popup behaviour on every published page. 

<script>
  document.addEventListener("DOMContentLoaded", function () {
    const twModalTrigger = document.querySelectorAll("[tw-modal-trigger]");
    const twModals = document.querySelectorAll("[tw-modal-content]");

    twModals.forEach((popup) => {
      popup.style.opacity = "0";
      popup.style.display = "none";
    });

    function closePopup(popup) {
      if (!popup || popup.style.opacity === "0") return;
      popup.style.transition = "opacity 0.3s ease";
      popup.style.opacity = "0";
      popup.addEventListener("transitionend", function handler() {
        popup.style.display = "none";
        document.body.style.overflow = "auto";
        popup.removeEventListener("transitionend", handler);
      });
    }

    twModalTrigger.forEach((btn) => {
      btn.addEventListener("click", function () {
        const popupAttr = this.getAttribute("tw-modal-trigger");
        if (!popupAttr) return;
        const popup = document.querySelector(`[tw-modal-content="${popupAttr}"]`);
        if (popup) {
          popup.style.display = "block";
          popup.getBoundingClientRect();
          popup.style.transition = "opacity 0.5s ease";
          popup.style.opacity = "1";
          document.body.style.overflow = "hidden";
        }
      });
    });

    document.querySelectorAll("[tw-modal-close]").forEach((closeBtn) => {
      closeBtn.addEventListener("click", function () {
        closePopup(this.closest("[tw-modal-content]"));
      });
    });

    document.addEventListener("keydown", function (e) {
      if (e.key !== "Escape") return;
      const openPopup = [...twModals].find((p) => p.style.opacity === "1");
      if (openPopup) closePopup(openPopup);
    });
  });
</script>

Step 2 — Copy a popup element

Choose the variant you need and click its Copy Element button. Then open your Webflow project, click anywhere on the canvas, and press Ctrl + V (Windows) or Cmd + V (Mac) to paste. The full popup structure — classes, attributes, and close button — will appear instantly.

Variant 1 Center Modal

Opens centered over the page with a dark backdrop. Uses .tw_modal-body (max-width 75%) and .tw_modal-scroll (max-height 90vh). Ideal for confirmation dialogs, forms, and rich content.

Variant 2 Side Drawer

Opens as a right-aligned panel with full viewport height. Uses .tw_modal-body-2 (max-width 50%, margin-left: auto) and .tw_modal-scroll-2 (height 100dvh). Ideal for detail panels, navigation drawers, and settings.

Step 3 — Add a trigger button

Select any button or element in the Navigator. In Element Settings, add a custom attribute named tw-modal-trigger with a value of 1 (or whichever number matches your pasted popup's tw-modal-content value). Clicking that element will now open the popup. 

<!-- Add this custom attribute to your trigger button -->
tw-modal-trigger = 1   <!-- matches tw-modal-content="1" -->

Step 4 — Using multiple popups

You can have as many popups on a page as you need. Each popup must have a unique tw-modal-content value, and its trigger button must carry the matching tw-modal-trigger value. For example, paste a second popup and change its tw-modal-content to 2, then set its trigger button's tw-modal-trigger to 2. 

<!-- First popup pair -->
<button tw-modal-trigger="1">Open Popup 1</button>
<div tw-modal-content="1" class="tw_modal">...</div>

<!-- Second popup pair -->
<button tw-modal-trigger="2">Open Popup 2</button>
<div tw-modal-content="2" class="tw_modal">...</div>
